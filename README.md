# Commonwealth Facility Energy Twin

Interactive 3D and satellite-referenced planning dashboard for Richmond Commonwealth facilities.

The site includes building-specific exterior and rooftop views, 25% / 50% / 75% / 100% rooftop PV scenarios, a full-year energy simulation, avoided emissions, avoided electricity cost, official facility imagery, monthly solar generation, and daily load/PV/grid analytics.

## GitHub Pages

Deployment is automated through GitHub Actions. Every change to `main` rebuilds and publishes the static dashboard.

> Planning note: energy, rooftop PV, EUI, cost, emissions, and modeled floor-area values are synthetic planning estimates. Facility locations, official exterior images, and cited public records are presented with source links in the dashboard.
